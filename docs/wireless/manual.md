# 无线款使用手册

本章面向已经完成烧录和组装的 **CH592F 5KEY / KNOB 无线款**。内容以当前固件和 BinaryKeyboard Studio 的实际行为为准，按“连接设备 → 日常使用 → 配置功能 → 维护恢复”的顺序介绍所有用户可见功能。

::: tip 首次烧录
还没有固件，或设备已经无法正常启动时，请先看 [刷写固件](./flash.md)。本章中的 Studio 更新只适用于能够正常连接的设备。
:::

## 1. 认识无线款

无线款支持两种工作模式：

| 模式 | 按键数据发送到 | 是否可连接 Studio |
| :--- | :--- | :--- |
| USB 模式 | USB-C 连接的电脑 | 可以 |
| BLE 模式 | 当前连接的蓝牙主机 | 插上 USB-C 后也可以 |

`FN1` 切换的是**按键数据走 USB 还是 BLE**。最新版固件在 BLE 模式下也会保留 USB 配置通道，因此改键、查看电量、备份配置或更新固件时，只需插上 USB-C，不必先切回 USB 模式。

::: warning 当前没有 2.4G 模式
固件只实现 USB 和 BLE。代码中的 2.4G 定义是预留项，成品目前不能连接 2.4G 接收器。
:::

### 5KEY

- 5 个普通按键，Studio 中显示为 K1～K5。
- 共 5 层。
- 出厂仅第 1 层有默认动作：K1～K5 分别输入 `1`、`2`、`3`、`4`、`5`。
- 第 2～5 层默认无动作，需要在 Studio 中配置。

### KNOB

- 4 个普通按键，外加旋钮顺时针、逆时针和按下 3 个虚拟键位。
- 共 4 层，旋钮不参与直接选层。
- 出厂仅第 1 层有默认动作：K1～K4 分别输入 `1`～`4`，旋钮顺时针为音量加，逆时针为音量减，按下为静音。
- 第 2～4 层默认无动作，需要在 Studio 中配置。

::: info 旋钮宏限制
旋钮的 3 个虚拟键位可以设置键盘、媒体、鼠标和层动作，但当前 Studio 不允许把宏直接绑定到旋钮虚拟键位。宏可以绑定到 K1～K4。
:::

## 2. 实体按键速查

| 操作 | 默认功能 | 结果 |
| :--- | :--- | :--- |
| 短按 `FN1` | 切换 USB / BLE | 保存目标模式并重启 |
| 长按 `FN1` 约 0.8 秒 | 切换 USB / BLE | 与短按相同 |
| 短按 `FN2` | 下一层 | 到最后一层后回到第 1 层 |
| 在 BLE 模式长按 `FN2` 约 2 秒 | 清除全部蓝牙绑定 | 清除后重启并重新广播 |
| 在 USB 模式长按 `FN2` | 默认无效果 | 不会清除蓝牙绑定 |
| 按住 `BOOT` + K1～Kn | 直接切到对应层 | 不执行该普通键原动作 |
| 单独按 `BOOT` | 无日常动作 | 不会进入 IAP / Bootloader |

`FN1` 和 `FN2` 的短按、长按动作可以在 Studio 中重新指定。上表只描述恢复出厂后的默认值。

## 3. USB 与 BLE 模式

### 使用 USB 模式

1. 用 USB-C 数据线连接键盘和电脑。
2. 如果当前是 BLE 模式，短按 `FN1`。
3. 设备保存目标模式并重启。
4. 重启后，普通按键、鼠标和媒体动作都通过 USB 发送。

切换模式会先释放正在按下的键，避免重启后出现 Ctrl、Shift 或鼠标键“卡住”。设备会记住最后一次模式，断电再开机仍进入该模式。

### 配对 BLE

1. 确保电池已连接且电量足够。
2. 短按 `FN1` 切到 BLE 模式；如果本来就在 BLE 模式，无需重复切换。
3. 在电脑、平板或手机的蓝牙设置中搜索：
   - 5KEY：`BinaryKeyboard5KEY`
   - KNOB：`BinaryKeyboardKNOB`
4. 选择设备并完成系统配对。

BLE 使用系统的“直接配对”流程，不需要在键盘上输入 PIN。一次只能与一台主机保持活动连接。

### 重新配对或更换主机

1. 确认键盘处于 BLE 模式。
2. 长按 `FN2` 约 2 秒。
3. 键盘清除全部绑定、重启并重新广播。
4. 在旧电脑或手机的蓝牙列表中也删除原来的 BinaryKeyboard。
5. 在新主机上重新搜索并配对。

::: warning 两端都要删除旧记录
只清键盘端或只删主机端，都可能留下不匹配的密钥，表现为“已配对但连不上”。排障时应同时清理两端。
:::

蓝牙广播单次最长约 60 秒。如果设备长时间搜索不到，可短按 `FN1` 切到 USB，再短按一次切回 BLE，以重新启动广播。

## 4. 使用层

层相当于多套独立键位。5KEY 有 5 层，KNOB 有 4 层。

### 依次切层

短按 `FN2` 切到下一层。最后一层之后会回到第 1 层。

### 直接切层

按住 `BOOT`，再按 K1、K2、K3……即可直达第 1、2、3……层。组合中的普通键不会执行原动作。

KNOB 的层选择只使用 K1～K4，旋钮不参与。

### 通过普通键切层

在 Studio 的按键编辑器中，普通键还可以设置三种层动作：

| 层动作 | 使用方式 |
| :--- | :--- |
| 切换 | 按一次进入目标层；如果已经在目标层，再按返回默认层 |
| 按住 | 按住时进入目标层，松开恢复到原层 |
| 跳转 | 按下后直接停留在目标层 |

当前层和最后一次工作模式会保存在设备中。快速连续切层时，固件会合并保存，减少 DataFlash 擦写。

### 层提示灯

每次切层时，对应位置的按键灯闪 3 次：

| 层 | 颜色 |
| :--- | :--- |
| 第 1 层 | 蓝色 |
| 第 2 层 | 绿色 |
| 第 3 层 | 黄色 |
| 第 4 层 | 紫色 |
| 第 5 层 | 红色 |

即使切到当前层，也会再次显示提示灯，便于确认层号。

## 5. 连接 BinaryKeyboard Studio

Studio 使用 WebHID。请使用 Chrome、Edge、Opera 等 Chromium 浏览器；Safari 和 Firefox 当前不能连接设备。

1. 用**支持数据传输**的 USB-C 线连接键盘。
2. 打开 BinaryKeyboard Studio。
3. 点击“连接设备”。
4. 在浏览器设备列表中选择 BinaryKeyboard 并授权。
5. 等待设备信息、键位、FN、RGB、宏和电量读取完成。

BLE 模式下无需先切换模式：蓝牙继续负责日常输入，USB 只承担 Studio 配置通信。Studio 不能直接通过蓝牙连接。

### 保存规则

- 键位修改：点击键盘卡片右上角的“保存配置”。
- FN、RGB、休眠参数和 Win / Mac 模式：在对应控件中修改后自动写入。
- 宏：在宏编辑器内单独点击“保存”。
- 页面出现“有未保存的更改”时，不要直接拔线。

## 6. 配置按键

先在左侧“层选择”中选择要编辑的层，再点击中央键盘上的目标键位。

### 键盘动作

点击“点击录入按键”，按下目标键，再按需要勾选 Ctrl、Shift、Alt、Win / Cmd 等修饰键。一个物理键可以直接发送组合键，例如 `Ctrl+S` 或 `Cmd+Shift+4`。

### 媒体动作

可选择播放 / 暂停、上一曲、下一曲、音量、静音、浏览器和亮度等标准 Consumer Control 动作。主机是否响应取决于操作系统和当前应用。

### 鼠标动作

支持左键、右键、中键、后退、前进，以及滚轮向上、向下和中键点击。

### 层动作

选择“切换”“按住”或“跳转”，再选择目标层。具体差异见本章前面的“使用层”。

### 宏动作

先在“宏管理”中创建宏，再回到按键编辑器选择宏及触发方式：

| 触发方式 | 使用效果 |
| :--- | :--- |
| 单次 | 每次按下执行一遍 |
| 按住·立停 | 按住时循环，松开立即终止 |
| 按住·跑完 | 按住时循环，松开后完成本轮再停止 |
| 切换循环 | 按一次开始循环，再按一次完成本轮后停止 |

切换层时，正在运行的宏会被取消。

## 7. 配置 FN1 / FN2

Studio 左侧“FN 键设置”分别提供 FN1、FN2 的“单击”和“长按”动作。改变下拉框后会自动保存。

当前界面可选：

- 无动作
- 切换模式
- 清除配对
- RGB 开关
- RGB 下一模式 / 上一模式
- 亮度加 / 亮度减
- 下一层 / 上一层
- 休眠

“清除配对”只在 BLE 模式执行，在 USB 模式会被静默忽略。“亮度加 / 减”每次改变 16/255，并立即保存。

::: warning 给自己保留恢复路径
如果把 FN1 的短按和长按都改成其他功能，就不能再靠默认按键切换 USB / BLE。给 FN1 或 FN2 至少保留一个“切换模式”动作。
:::

## 8. Win / Mac 系统模式

“键盘状态”卡片中可以切换 Win / Mac：

- Win 模式：按配置原样发送 Ctrl 和 Win。
- Mac 模式：发送键盘报告时自动交换左右 Ctrl 与 GUI（Command）修饰位。

这个设置会同时影响 USB 和 BLE。普通字母、数字、媒体键等不会改变。它只改变修饰位解释，不会自动把所有 Windows 快捷键改写成 macOS 快捷键。

## 9. RGB 和状态指示灯

### 按键灯模式

Studio 的“RGB 灯效”支持：

- 关闭
- 静态
- 呼吸
- 闪烁
- 彩虹
- 仅指示灯

还可以调整按键灯亮度、指示灯亮度、动画速度、静态 / 呼吸颜色，以及“按下亮起渐灭”“按下熄灭渐亮”两种按键反馈。

RGB 总开关只关闭按键灯。状态指示灯和层提示仍会工作，避免无线状态完全不可见；指示灯亮度最低保留约 5%。

### 状态指示

| 状态 | 指示效果 |
| :--- | :--- |
| USB 已连接 | 白色短亮 |
| BLE 未连接 | 红色慢呼吸 |
| BLE 广播中 | 蓝色呼吸 |
| BLE 已连接 | 绿色短亮 |
| 电量不高于 10% | 橙红色快闪 |
| 进入休眠 | 蓝青色闪 3 次，随后熄灭 |

固件还定义了充电中的琥珀色脉冲，但当前默认硬件构建关闭了独立充电状态检测，因此 Studio 和指示灯通常只显示估算电量，不保证显示“充电中”。

## 10. 电池与低功耗

### 查看电量

插上 USB 并连接 Studio，“键盘状态”会显示：

- 估算电量百分比
- 电池电压
- 充电状态（仅在硬件和固件启用充电检测时可靠）

固件每约 30 秒采样一次电池电压，并按锂电池放电曲线估算百分比。电压百分比不是库仑计结果，负载变化或刚插拔充电线时出现小幅跳动属于正常现象。

### 自动休眠

默认设置：

- 空闲 1 分钟进入 LIGHT 低功耗。
- 再空闲 1 分钟进入 DEEP 深度休眠，即总空闲约 2 分钟。
- 在 Studio 的 RGB 面板中把任一时间设为 `0` 可禁用对应阶段。

进入休眠前，指示灯会蓝青色闪 3 次；LIGHT 会关闭按键扫描定时器、电池采样和 LED 电源，按键可唤醒；DEEP 会关机，按键唤醒相当于重新启动。

USB 已完成枚举时不会自动休眠。唤醒后会恢复保存的工作模式和当前层；BLE 和 2.4G 深睡唤醒后需要等待无线链路重新建立，首键只负责唤醒。

也可以把 FN 的单击或长按动作改为“休眠”，手动立即进入 LIGHT。

## 11. 宏

### 创建宏

1. 打开左侧“宏管理”。
2. 选择已有宏，或选择末尾的新建入口。
3. 在“可视”模式添加按键、修饰键、鼠标、滚轮或媒体动作，也可以点击“录制”。
4. 为动作调整延时；按下和释放必须成对、顺序正确。
5. 点击“保存”。
6. 回到键位编辑器，把宏绑定到普通按键，并选择触发方式。

### MeowMacro 模式

宏编辑器可以切换到 MeowMacro 文本模式，支持语法高亮、补全、错误提示和“编译简化”。语法与示例见 [MeowMacro](../meowmacro.md)。

### 当前限制

- CH592F 使用动态 MeowFS，不是固定 8 个宏槽。
- 每个宏最多 255 个底层动作。
- 所有宏合计使用约 8KB 空间；编辑器左下角会显示剩余容量。
- CH592F 当前不在设备端保存宏名称，界面以“宏 1、宏 2……”识别。
- 删除中间宏后，后续宏会前移；Studio 会同步修正可识别的按键 / FN 引用。
- 旋钮虚拟键位当前不能绑定宏。

宏可以单独导入 / 导出为 JSON。需要迁移整套设备设置时，优先使用“配置库”。

## 12. 配置库

“配置库”可保存完整设备快照，包括键位、RGB、FN、Win / Mac 模式、日志配置和宏。

可执行：

- 保存当前配置
- 恢复到设备
- 导入 / 导出 `.binarykeyboard-config.json`
- 重命名或删除配置

网页中的配置库保存在当前浏览器的 IndexedDB 中。清理网站数据、换浏览器或换电脑前，应先导出 JSON。恢复时 Studio 会检查协议、型号、层数、键位数量和宏容量；不兼容配置不会直接写入。

## 13. Debug Terminal

点击 Studio 底部的“Debug Terminal”可以查看：

- Studio 发出的 HID 命令（TX）
- 设备响应（RX）
- 按键、FN、层、模式、BLE、RGB 和系统事件（DEV）
- 命令耗时、状态码、解析内容和原始十六进制数据

点击齿轮可开启“HID 日志”并保存；类别过滤只影响当前界面显示。排查蓝牙掉线、按键映射或保存失败时，保留出现问题前后的日志最有价值。

## 14. 固件更新

### 正常在线更新

1. 用 USB-C 连接设备；BLE 工作模式也可以。
2. 连接 Studio，打开设备信息 / 固件更新。
3. 选择“更新到最新版本”或“重刷当前版本”。
4. 等待 `CH592F-<MODEL>-<version>-app.bin` 写入完成。
5. 设备重启后重新连接 Studio，确认固件版本。

更新期间不要拔线、关闭页面或让电脑休眠。

### 首刷和救砖

设备不能正常连接 Studio 时，使用对应型号的 `CH592F-<MODEL>-<version>-full.hex` 走 WCH ISP。`app.bin` 不是首刷包。详见 [刷写固件](./flash.md)。

## 15. 恢复出厂设置

在 Studio 中执行“恢复出厂设置”会：

- 恢复默认键位、FN、RGB、休眠和 Win 模式配置
- 删除全部宏

它不会代替“清除蓝牙配对”。如果问题涉及配对，请恢复后再到 BLE 模式长按默认 `FN2`，并删除主机端旧设备。

如果已把 FN 改到无法切换模式，仍可在 BLE 模式插 USB 连接 Studio 改回；如果 Studio 也无法连接，再使用 `-full.hex` 恢复。

## 16. 常见现象速查

| 现象 | 先这样处理 |
| :--- | :--- |
| Studio 找不到设备 | 换支持数据的 USB-C 线；使用 Chrome / Edge；重新授权 WebHID |
| BLE 模式插线后仍显示 BLE | 正常；工作模式决定按键去向，USB 配置通道仍可用 |
| 已配对但无法连接 | 键盘端长按 `FN2` 清绑定，同时删除主机端旧记录 |
| 搜不到蓝牙名称 | 重新切入 BLE 以启动广播；确认型号名称；检查电量 |
| 第 2 层以后按键无反应 | 出厂仅第 1 层有动作，请在 Studio 配置并保存 |
| RGB 关闭后还有一颗灯 | 正常；状态指示灯独立保留 |
| Studio 不显示充电中 | 当前默认构建未启用独立充电检测，以电压和实际充电器状态为准 |
| 宏不能绑定到旋钮 | 当前限制；改绑到 K1～K4 |
| 改完键位没生效 | 检查是否点了“保存配置”，以及编辑层和当前层是否一致 |

更多诊断见 [常见问题](../faq.md)。
