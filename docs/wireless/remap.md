# 无线版改键软件

CH592F 无线款使用 BinaryKeyboard Studio 配置键位、FN、RGB、系统模式、宏和低功耗参数。本页说明配置流程；日常操作和状态灯含义见 [无线款使用手册](./manual.md)。

## 连接要求

| 项目 | 要求 |
| :--- | :--- |
| 连接 | 支持数据传输的 USB-C 线 |
| 浏览器 | Chrome / Edge / Opera 等 Chromium 浏览器 |
| 协议 | WebHID |
| 不支持 | Safari、Firefox、直接通过 BLE 配置 |

::: tip BLE 模式也能配置
最新版 CH592F 固件在 BLE 工作模式下也会初始化 USB 配置通道。插上 USB-C 后可直接连接 Studio，不必先按 `FN1` 切回 USB；此时日常按键仍发送给蓝牙主机。
:::

## 连接 Studio

1. 用 USB-C 连接键盘和电脑。
2. 打开 BinaryKeyboard Studio。
3. 点击“连接设备”。
4. 在浏览器设备选择框中选择 BinaryKeyboard。
5. 授权后等待设备信息、状态和配置读取完成。

如果列表里没有设备，请先确认数据线不是仅充电线，再检查浏览器的网站 HID 权限。

## 界面功能

无线款连接后可使用：

- 键盘状态：电量、电压、USB / BLE 工作模式、RGB、Win / Mac 模式
- 层选择：5KEY 为 5 层，KNOB 为 4 层
- 键位编辑：键盘、修饰键、媒体、鼠标、层动作和宏
- FN 键设置：分别配置 FN1 / FN2 的单击和长按
- RGB 灯效：灯效、颜色、亮度、速度、按下反馈和休眠时间
- 配置库：保存、恢复、导入、导出整套配置
- 宏管理：可视编辑、录制、MeowMacro、导入和导出
- Debug Terminal：查看 HID 请求、响应和设备事件
- 设备信息与固件在线更新
- 恢复出厂设置

## 编辑键位

1. 在左侧“层选择”中点击要编辑的层。
2. 点击中央键盘上的目标按键或旋钮动作。
3. 选择动作并点“确定”。
4. 继续修改其他键位。
5. 点击键盘卡片右上角“保存配置”。

“当前层”是设备此刻实际使用的层，“编辑层”是 Studio 中正在修改的层，两者可以不同。页面显示“有未保存的更改”时，改动尚未写入设备。

### 键盘

点击“点击录入按键”，按下目标键，再选择左右 Ctrl、Shift、Alt、Win / Cmd 等修饰键。一个键位可以直接配置组合键。

### 媒体

支持播放 / 暂停、上一曲、下一曲、音量、静音、浏览器、亮度等标准媒体控制。

### 鼠标

支持左键、右键、中键、后退、前进，以及滚轮向上、向下和中键点击。

### 层

| 操作 | 行为 |
| :--- | :--- |
| 切换 | 进入目标层；已在目标层时返回默认层 |
| 按住 | 按住时进入目标层，松开恢复 |
| 跳转 | 直接设置并停留在目标层 |

### 宏

先创建至少一个宏，再选择宏和触发模式。KNOB 的旋钮顺时针、逆时针、按下属于虚拟键位，当前 Studio 不允许直接绑定宏；K1～K4 可以。

## 配置 FN

“FN 键设置”可分别设置 FN1、FN2 的单击和长按：

- 无动作
- 切换模式
- 清除配对
- RGB 开关
- RGB 下一模式 / 上一模式
- 亮度加 / 减
- 下一层 / 上一层
- 休眠

下拉框改变后会自动保存。默认长按阈值为 FN1 约 800ms、FN2 约 2000ms，当前界面不提供阈值编辑。

::: warning
“清除配对”只在 BLE 模式执行。重新分配 FN 前，保留至少一个“切换模式”入口。
:::

## 配置 Win / Mac 模式

在“键盘状态”中选择：

- Win：Ctrl 和 Win 按配置原样发送。
- Mac：固件发送时自动交换左右 Ctrl 与 GUI（Command）修饰位。

切换后自动保存，并同时作用于 USB 和 BLE。

## 配置 RGB 和休眠

“RGB 灯效”中可以调整：

- RGB 总开关
- 关闭、静态、呼吸、闪烁、彩虹、仅指示灯
- 静态 / 呼吸颜色
- 按键灯亮度和独立指示灯亮度
- 动画速度
- 无、按下亮起渐灭、按下熄灭渐亮
- LIGHT 休眠分钟数
- DEEP 延时分钟数

设置改变后自动保存。RGB 总开关只关闭按键灯，状态指示灯和层提示仍保留。默认 LIGHT 为 1 分钟，DEEP 为 LIGHT 后再 1 分钟；填 `0` 可禁用对应阶段。

## 宏编辑器

### 创建和保存

1. 点击“宏管理”。
2. 在左侧选择已有宏或末尾的新建入口。
3. 在“可视”模式手动添加动作或点击“录制”。
4. 调整动作和延时。
5. 确认按下 / 释放成对且顺序正确。
6. 点击“保存”。
7. 回到键位编辑器，把宏绑定到普通键。

可视模式支持：

- 普通按键按下 / 释放
- 左右修饰键按下 / 释放
- 鼠标五键和滚轮
- 媒体控制
- 动作后延时
- 拖拽排序
- 键盘操作录制

### MeowMacro

切换到“MeowMacro”可以直接编写脚本，编辑器提供高亮、补全、错误定位和编译简化。完整语法见 [MeowMacro](../meowmacro.md)。

### 宏容量

CH592F 当前使用动态 MeowFS：

- 宏数量不是固定 8 个，编辑器始终在已用宏后提供一个新建入口。
- 单个宏最多 255 个底层动作。
- 所有宏共享约 8KB 空间。
- 左侧显示剩余字节数。
- CH592F 当前不在设备端保存宏名称，因此按“宏 1、宏 2……”显示。

删除中间宏会使后续宏前移，Studio 会同步修正它能识别的键位 / FN 宏引用。删除前先用“配置库”备份。

### 宏触发模式

| 模式 | 行为 |
| :--- | :--- |
| 单次 | 按下执行一遍 |
| 按住·立停 | 按住循环，松开立即终止 |
| 按住·跑完 | 松开后完成当前一轮再停 |
| 切换循环 | 再按一次后完成当前一轮再停 |

宏可以单独导入 / 导出 `.binarykeyboard-macro.json`。

## 配置库

配置库保存完整快照：键位、RGB、FN、系统模式、日志配置和宏。

1. 点击“配置库”。
2. 用“保存配置”读取当前设备并命名。
3. 需要跨浏览器或跨电脑时，选择配置并“导出配置”。
4. 恢复时先导入 JSON，再点“恢复配置”。

本地配置库保存在当前浏览器 IndexedDB 中；清除网站数据会删除它。导入文件带 SHA-256 完整性校验，恢复前还会检查设备协议、型号、层数、键数和宏容量。

## Debug Terminal

点击底部“Debug Terminal”展开面板。它可以显示 TX、RX 和设备事件，支持自动滚动、清空、分类过滤和详细十六进制帧。

需要设备主动上报事件时：

1. 点击终端右上角齿轮。
2. 打开“HID 日志”。
3. 点击“保存”。
4. 复现问题并保留前后日志。

## 固件在线更新

设备能够正常连接 Studio 时：

1. 打开设备信息 / 固件更新。
2. 选择“更新到最新版本”或“重刷当前版本”。
3. Studio 下载对应型号的 `CH592F-<MODEL>-<version>-app.bin`。
4. 等待写入和重启完成，再重新连接确认版本。

首次烧录或救砖必须使用对应型号的 `-full.hex` 走 WCH ISP，不能把 `app.bin` 当成首刷包。详见 [刷写固件](./flash.md)。

## 恢复出厂设置

在 Studio 中确认“恢复出厂设置”后，会恢复默认键位、FN、RGB、休眠和 Win 模式，并删除全部宏。

蓝牙绑定记录属于独立区域，不会随普通配置重置。需要彻底重新配对时，还要在 BLE 模式执行“清除配对”，并删除主机端旧设备。

## 常见问题

### BLE 模式下 Studio 显示的是 BLE 模式，正常吗？

正常。工作模式表示日常输入数据的去向，不表示 USB 配置通道是否存在。

### 改键后没有生效

确认点击了“保存配置”，并确认编辑层就是当前使用层。FN、RGB、系统模式和宏有各自的保存流程。

### 蓝牙配对后改键不生效

配置写入设备后同时作用于 USB 和 BLE。请确认 Studio 已提示保存成功，再断开 USB 测试；无需为了保存而切换工作模式。

### 如何重新配对？

在 BLE 模式长按默认 `FN2` 约 2 秒清除键盘端绑定，同时删除电脑 / 手机蓝牙列表中的旧设备，再重新搜索 `BinaryKeyboard5KEY` 或 `BinaryKeyboardKNOB`。

### 如何恢复默认配置？

设备能连接 Studio 时使用“恢复出厂设置”。无法连接时，用对应型号的 `CH592F-<MODEL>-<version>-full.hex` 重新首刷 / 恢复。
