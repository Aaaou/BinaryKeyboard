# 无线版硬件复刻

当前仓库没有随代码维护的 CH592F 原理图、PCB 文件或可核验的 OSHWHub 项目链接。旧页面中的 BOM 来自早期原型，和现有 5KEY / KNOB 固件布局、FN 定义及电源检测配置无法一一对应，已移除，避免按错误物料下单。

## 现有板子的刷写与使用

如果你已经有与发布固件匹配的 PCB：

1. 确认是 5KEY 或 KNOB，并使用同型号的 `CH592F-<MODEL>-<version>-full.hex`。
2. 首刷和恢复按 [刷写固件](./flash.md) 操作。
3. 使用和配置按 [无线款使用手册](./manual.md) 操作。

## 新建硬件前需要确认的边界

从头复刻或改板时，先固定以下事项：

| 项目 | 当前固件约束 |
| :--- | :--- |
| 目标布局 | `5KEY` 或 `KNOB`，两者不能共用固件 |
| 输入 | 5KEY 为 5 个普通键；KNOB 为 4 个普通键和 1 个编码器 |
| 功能键 | `BOOT`、`FN1`、`FN2`；其中 BOOT 用于首刷和直接选层 |
| 无线 | CH592F BLE；当前没有 2.4G 接收器模式 |
| 电池 | 单节锂电池，电压采样使用 PA14 / PA15 |
| RGB | WS2812 数据 PA10，使能 PA9 |

完整 GPIO 定义见 `firmware/CH592F/hal/include/kbd_config.h`。该文件是固件引脚映射的依据，不等同于生产级原理图。

## 上板顺序

1. 先验证电源轨、USB-C 和 BOOT 下载。
2. 再焊 CH592F、时钟和基础外围，确认 ISP 能识别。
3. 烧录对应 `-full.hex`，检查 USB 枚举和 BLE 广播。
4. 最后接入按键、编码器、电池和 WS2812，逐项测试。

电池极性、充电电路和天线区域必须按最终原理图检查。没有经过实物验证的 BOM、天线尺寸或充电参数不应直接用于生产。
