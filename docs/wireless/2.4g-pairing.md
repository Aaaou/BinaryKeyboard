# CH592F 2.4G 配码与接收器设计

> 状态：分支 `feat/ch592-2g4-pairing` 已提供独立 RF-only 键盘镜像和 CH592F 接收器镜像。两类镜像均已交叉编译通过，但真实配码、距离、丢包率和功耗仍需两块 CH592F 实物验收。普通 USB/BLE release 不链接 RF FAST，也不能当作 2.4G 固件使用。

## 运行模式与轮询率

由于 WCH RF FAST 与 BLE 库包含冲突的底层基带实现，当前 2.4G 键盘是独立 RF-only 镜像，不是 USB/BLE/2.4G 三模单镜像。普通 BLE 固件保持原来的 `USB <-> BLE`，RF-only 镜像启动后固定使用 2.4G，并保留 USB Vendor HID 供 Studio 配码。

接收器使用 USB Full-Speed HID，支持 `125 / 250 / 500 / 1000 Hz`，默认 `1000 Hz`。设置入口是 Studio 的“2.4G 无线与接收器”，设置写入接收器 DataFlash。USB 描述符固定提供 1 ms 端点，较低轮询率由接收器合并报告实现。CH592F USB Full-Speed 的主机侧上限约为 1000 Hz，不提供没有实际收益的 2K/4K/8K 选项。

## 灯光状态

以下灯光是后续板级适配目标，当前镜像尚未接入 RGB，不能作为本轮测试依据：

| 状态 | 灯光 |
| --- | --- |
| 接收器无绑定，自动等待配码 | 蓝色双闪，约每秒一次，持续 60 秒 |
| Studio 或 FN 手动开始配码 | 紫色快闪，持续 60 秒 |
| 配码成功 | 绿色常亮约 500 ms，随后进入连接状态 |
| 配码超时或验证失败 | 红色闪 3 次 |
| 双端解绑成功 | 黄色闪 2 次 |
| 2.4G 已连接 | 沿用无线连接指示；不长期占用 RGB 灯效 |

## 首次配对

1. 首次给接收器烧录接收器固件后插入电脑。接收器没有有效绑定记录，会自动进入 60 秒蓝色双闪窗口。
2. 用 USB 连接 RF-only 键盘，在 Studio 的“2.4G 无线与接收器”点击“开始配码”。
3. 接收器和键盘通过 WCH RF FAST 的 Host/Device 绑定流程交换 PeerInfo，并分别写入 DataFlash。
4. Studio 显示“已绑定”或“已连接”后，断电重启两端确认绑定能够恢复。当前没有 RGB 状态提示，以 Studio 状态为准。

键盘默认没有配码 FN 绑定。RF-enabled 固件连接 Studio 后，才会在 FN 的“长按”下拉项中出现“进入 2.4G 配码”；建议把它放在长按，不要放在普通点击。日常配码不依赖 BOOT 引脚，PB22 改接 PB11 仅保留给恢复刷写。

## 清除与重新配码

当前“清除绑定”只清除 Studio 正在连接的一端，没有伪装成已经完成双端事务：

- 清除接收器后，接收器不是废设备。它清空本地记录并立即自动开启 60 秒配码窗口。
- 清除键盘后，键盘进入未绑定状态。接收器仍保存旧记录，因此还需要连接接收器执行一次“清除绑定”，再让两端重新配码。

常规换键盘、换接收器或转售前，应分别清除两端，再重新配码。双端确认式解绑属于后续增强项。

## Studio 与 HID 协议

Studio 通过 HID Vendor 接口发现设备及其 collection；它不读取或展示原始 HID report descriptor 作为配置协议。设备信息、角色、配码状态、轮询率和配码控制都走有版本的 Vendor HID 命令：

```text
RADIO_CAPS           当前角色、是否启用 RF、支持的轮询率
RADIO_PAIR_STATUS    unbound / pairing / bound / connected / inconsistent
RADIO_PAIR_START     开启 60 秒配码窗口
RADIO_PAIR_CANCEL    取消本次窗口
RADIO_PAIR_CLEAR     发起双端解绑事务
RADIO_POLL_RATE_GET  读取接收器 USB 轮询率
RADIO_POLL_RATE_SET  设置 125/250/500/1000 Hz
```

绑定数据只向 Studio 返回角色、状态、会话编号和非敏感设备标识，不通过网页读取或导出 PeerInfo。

## 实现边界

本分支已提供可链接的 RF FAST Host/Device 与接收器 USB HID 路径，并直接复用 WCH 官方 RF FAST 库的绑定、跳频、确认和重发状态机。应用层额外使用 magic/version/sequence/CRC16 校验。尚未完成的验收包括：两板真实绑定、长按与高频输入、断电恢复、抗干扰距离、丢包率、功耗、应用层加密以及双端确认式解绑。旧固件仍不会误开启 2.4G 功能。
